# 自托管字体

## 站酷庆科黄油体 ZCOOL QingKe HuangYou
- 来源：Google Fonts https://fonts.google.com/specimen/ZCOOL+QingKe+HuangYou
- 许可：SIL Open Font License 1.1
- 形式：92 个 unicode-range 分片（`zcool/`），共约 1.82MB，由 `zcool.css` 声明
- **必须自托管**：CDN 声明成功但实际可能不加载，标题会静默回退成细体
- **路径坑**：CSS 的 `url()` 相对 CSS 文件自身解析，`zcool.css` 内须写 `zcool/zcool-XX.woff2`
